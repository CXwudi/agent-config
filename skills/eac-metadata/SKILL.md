name: eac-metadata
description: Agent Skill for generating pastable metadata for EAC (Exact Audio Copy). Use only when user requests it
---

2. If any, identify user's desired format, espacially for vocaloid albums
3. Generate the pastable metadata for the user to copy
4. Provide instruction on how to use the copied metadata in EAC (Assuming user are using latest GA version of EAC)
