# User Browser

This is a combination of 2 skills, choose one of below:

- [`opencli`](./opencli/SKILL.md)
- [`agent-browser`](./agent-browser/SKILL.md)

How to choose:

1. `agent-browser` for:
    - Web development, testing, and debugging
    - Launch new browser
2. `opencli` for:
    - Anti-automation detection
