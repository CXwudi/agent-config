# Jina Crawl

## Prerequisites

`JINA_API_KEY` env var is available.

## REST 

Use the `openapi-inspection` skill to read Jina OpenAPI specs at `https://r.jina.ai/openapi.json` and `https://s.jina.ai/openapi.json`.

Then make REST API calls following the spec.
