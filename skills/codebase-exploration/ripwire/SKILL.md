## Prerequisites

Run `ripwire` once, you should get some help message like this:

```
ripwire: no <dir> given. the repository to map is the one required argument.
  ripwire .                     the ranked map of the current directory
  ripwire . --for="TASK"        the task lens: what to read first
  ripwire --help                every flag, one line each
  ripwire --help=--for          one flag in full  (also --help=<section>, --help=all)
```

## Usage

Simply explore the usage yourself by running the help message above.

In short, it can index the codebase and provide graph for you to help explore the codebase efficiently.
You can also ask question about the codebase in plain text.

## Note

Do not setup any Agent Skill or MCP server for ripwire. This skill is the only skill you need to use ripwire.
